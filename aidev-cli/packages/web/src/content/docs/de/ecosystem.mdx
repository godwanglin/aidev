Eine Sammlung von Community-Projekten, die auf AidevCLI basieren.

:::note
Möchten Sie Ihr AidevCLI-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-aidev-cli](https://github.com/awesome-aidev-cli/awesome-aidev-cli) und [aidev-cli.cafe](https://aidev-cli.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
