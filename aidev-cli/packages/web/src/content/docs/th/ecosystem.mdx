ชุดโครงการชุมชนที่สร้างขึ้นบน AidevCLI

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ AidevCLI ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-aidev-cli](https://github.com/awesome-aidev-cli/awesome-aidev-cli) และ [aidev-cli.cafe](https://aidev-cli.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
